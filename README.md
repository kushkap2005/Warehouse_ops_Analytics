# 🏭 Warehouse Operations Analytics

A Python + SQLite + Excel project that generates a simulated warehouse dataset and analyses it with SQL to produce business insights and an Excel dashboard, the way a supply chain analyst would.

> **Note:** All data is synthetic, generated by `generate_data.py` (fixed random seed). Some patterns, such as slower fulfilment at peak hours and higher evening delivery cost, are built into the generator, so the findings below show the analysis pipeline working on simulated data rather than real-world discoveries.

---

## 📁 Project Structure

```
warehouse-ops-analytics/
├── data/
│   ├── orders.csv              ← 5,000 synthetic orders (30 days)
│   ├── skus.csv                ← 36 SKUs across 6 categories
│   ├── pickers.csv             ← 8 warehouse pickers with shift data
│   ├── deliveries.csv          ← Delivery records with cost + distance
│   ├── picker_uph.csv          ← UPH analysis per picker
│   ├── sku_velocity.csv        ← SKU velocity ranking
│   ├── peak_hours.csv          ← Hourly order volume
│   ├── daily_trend.csv         ← 30-day order trend
│   ├── reorder_alerts.csv      ← Stock replenishment alerts
│   ├── slot_cost_analysis.csv  ← Delivery cost by time slot
│   ├── category_tat.csv        ← Fulfilment TAT by category
│   ├── delivery_status.csv     ← Delivery outcome summary
│   ├── dow_performance.csv     ← Day-of-week performance
│   └── kpi_summary.csv         ← Headline KPIs
├── generate_data.py            ← Creates all synthetic data + loads SQLite
├── analysis.py                 ← 10 SQL business queries via Pandas
├── dashboard.py                ← Builds the 6-sheet Excel dashboard
├── warehouse_ops.db            ← SQLite database (auto-created)
├── Warehouse_Operations_Dashboard.xlsx  ← Final Excel output
└── README.md
```

## 🚀 How to Run

### Prerequisites
```bash
pip install pandas openpyxl numpy
```

### Step 1 — Generate Data
```bash
python generate_data.py
```
Creates 4 CSV files in `data/` and loads them into `warehouse_ops.db`.

### Step 2 — Run Analysis
```bash
python analysis.py
```
Executes 10 SQL business queries and saves results as CSVs in `data/`.

### Step 3 — Build Dashboard
```bash
python dashboard.py
```
Produces `Warehouse_Operations_Dashboard.xlsx` — a professional 6-sheet Excel dashboard.

## 💡 Business Insights (from the simulated data)

All figures below come from the CSVs in `data/` (5,000 orders, 1–30 Mar 2024).

1. **Peak hours are slower.** 50% of orders arrive in 7 of 24 hours (10:00–12:59 and 17:00–20:59), about 358 orders/hour against 147 outside them. Average fulfilment time in those hours is 65.3 min vs 52.6 min otherwise, roughly 13 minutes longer. *Suggestion: add picker capacity in these windows.*

2. **Evening delivery slots cost more.** The 18:00–21:00 slot averages ₹104 per delivery vs ₹88 for 09:00–12:00 (about 19% more). *Suggestion: test an incentive to move customers to cheaper slots; the saving is not estimated here.*

3. **Sales are concentrated.** The top 20% of SKUs account for about 49% of sales value; the bottom 20% for about 2%.

4. **Picker performance is tightly clustered.** All 8 pickers fall between 5.4 and 5.8 units/hour (average 5.58), so there is no clear underperformer in this data.

5. **Stock alerts.** 6 of 36 SKUs are at or below reorder level (3 Electronics, 1 Home & Kitchen, 1 Books, 1 Stationery), and 9 are within 1.5× of it. No SKU is out of stock.

6. **Delivery outcomes.** 90.3% delivered, 5.3% delayed, 4.4% returned.
